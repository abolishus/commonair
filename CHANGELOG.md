## [Unreleased]

### Added

- Initial project scaffolding: Bun monorepo with `apps/`, `services/`,
  `packages/`, the Go `relay/`, `harness/`, `infra/`, and `docs/`.
- Licensing: AGPL-3.0-or-later for code, CC-BY-SA-4.0 for documentation,
  CC0-1.0 for small configuration files; REUSE 3.3 compliance.
- `bun run verify` as the single verification gate.
- Project documents: contributing guide, code of conduct, trademark policy,
  security policy, governance, roadmap, and issue and pull request templates.
- ADR 0001: the platform is named CommonAir.
