# Trademark Policy

The CommonAir code is free software under AGPL-3.0-or-later. You may use,
study, change, self-host, and fork it, subject to that license. This policy
does not restrict any right the license gives you.

The **CommonAir** name and logo are a different matter. They belong to the
CommonAir cooperative (in formation), on behalf of its members. They tell
people that what they are using is the co-op's platform, run under the co-op's
rules. This policy exists so that promise stays true.

## Forks must rebrand

If you distribute or run a modified version, give it a different name and
logo. The project is set up so that this is one change:

- Edit `packages/config/src/site.ts` (name, slug, domain, contacts, repository).
- Replace the logo assets.

Nothing else in the code hard-codes the name or domain; the stray-domain check
in CI enforces that.

## Allowed without asking

- Saying your project is "a fork of CommonAir" or "based on CommonAir".
- Saying your software is "compatible with CommonAir" or "works with
  CommonAir", when it is.
- Running an **unmodified** release of CommonAir and saying it is "powered by
  CommonAir".
- Referring to CommonAir by name in articles, reviews, talks, tutorials, and
  discussion.

## Not allowed without permission

- Calling a modified version "CommonAir", or using a confusingly similar name.
- Using the logo for a modified version, or altering the logo.
- Suggesting the co-op endorses, operates, or is affiliated with your project,
  instance, or product when it does not.
- Using "CommonAir" or a similar name in a domain name, app store listing, or
  social media handle.
- Selling merchandise with the name or logo.

## Asking permission

Write to governance@commonair.tv describing what you want to do. We aim to
answer within two weeks. Permission is given in writing and can be limited in
scope or time.

If you are unsure whether a use is fine, ask. We would rather say yes early
than argue later.
