## Build

1. **Single `compose.yaml`** that brings up the whole platform with `podman compose up` (podman-compose 1.6 on macOS via podman machine, and Linux rootless). Rootless rules: no `privileged`, no host ports < 1024, no container-engine socket mounts, fully-qualified pinned images, named volumes, `userns`-friendly file permissions, `restart: unless-stopped`, healthchecks on everything, `depends_on: condition: service_healthy` where supported. Host port bindings on `127.0.0.1` by default (an env var `BIND_ADDRESS` may change it) and all host ports configurable via env with defaults (`${POSTGRES_PORT:-5432}` etc.) so a second stack can run alongside.
   Services: `postgres` (custom image, see 3), `migrate` (one-shot: runs `bun packages/db/src/migrate.ts` as the DB owner, then creates/updates the least-privilege application role `commonair_app` with DML-only grants and no TRUNCATE/TRIGGER/REFERENCES and `REVOKE CREATE ON SCHEMA public`, `REVOKE TEMP` from it; app services connect as `commonair_app` — write this as `infra/postgres/app-role.sql` applied by the migrate job), `valkey`, `garage` (`docker.io/dxflrs/garage:v2.4.1` with `infra/garage/garage.toml` templated from env) + `garage-init` (one-shot Bun container running `infra/garage/bootstrap.ts`: uses Garage's admin API v2 to assign/apply the single-node layout, import the access key pair from `S3_ACCESS_KEY_ID`/`S3_SECRET_ACCESS_KEY` (Garage key format GK… + 64 hex), create the three buckets and grant the key; idempotent), `mailpit`, `mediamtx` (`docker.io/bluenviron/mediamtx:1.21.2-ffmpeg`, config from `infra/mediamtx/mediamtx.yml`, ports 1935/8554 internal/8888 internal/8889/8189udp/9997 internal), `mock-rtmp` (profile `harness`: second mediamtx with `infra/mediamtx/mock-rtmp-target.yml` on 1936), `api`, `chat`, `irc`, `origin`, `media`, `worker`, `tracker`, `web` (all built from one `infra/containers/service.Containerfile` with build-arg `SERVICE`; Bun base `docker.io/oven/bun:1.4.3-slim`; multi-stage: install deps with `bun install --frozen-lockfile --production` filtered to the service's workspace closure, copy sources, non-root user, `HEALTHCHECK` hitting the service health port; the `media` variant installs `ffmpeg` from Debian apt; the `web` variant runs the TanStack Start build output — design the Containerfile so the web build step runs `vp build` in `apps/web` when `SERVICE=web`), `otel-collector`, `prometheus`, `loki`, `tempo`, `grafana` (provisioned datasources for Prometheus/Loki/Tempo from `infra/grafana/provisioning/`; dashboards folder created empty — dashboards are a later unit; anonymous read-only disabled; admin password from env), `caddy` (profile `tls`: TLS termination for a real domain via `infra/caddy/Caddyfile` templated by env `PUBLIC_HOSTNAME`; routes `/` → web, `/api` and `/rpc` → api, `/chat` → chat ws, `/hls`, `/relay-pull`, `/cdn` → origin, `/tracker` → tracker; never routes `/internal/*`; security headers incl. CSP, HSTS), `stripe-mock` (profile `stripe`: `docker.io/stripe/stripe-mock:v0.206.0`).
   Log shipping: containers log JSON to stdout; the otel-collector `filelog` receiver can't read podman logs portably — instead configure services to export logs via OTLP to the collector (env `OTEL_EXPORTER_OTLP_ENDPOINT=http://otel-collector:4318`) and the collector exports logs to Loki (OTLP → Loki native OTLP endpoint), traces to Tempo, metrics to Prometheus (remote write or scrape the collector's Prometheus exporter). Document the pipeline.
   Env: services read the `.env` file (`env_file: .env`) plus per-service overrides (hostnames inside the compose network: `DATABASE_URL=postgres://commonair_app:...@postgres:5432/commonair`, `VALKEY_URL=redis://valkey:6379`, `S3_ENDPOINT=http://garage:3900`, `MEDIAMTX_*` to `mediamtx`, `API_INTERNAL_URL=http://api:3001`, `CHAT_INTERNAL_URL=ws://chat:3002/ws`, `ORIGIN_INTERNAL_URL=http://origin:3003`, `SMTP_HOST=mailpit`). The app-role password is `databaseEnv.POSTGRES_APP_PASSWORD` (already in `.env.example`, generated by init-env). Any other new env var you need: report it as a contract request with defaults; meanwhile use `${VAR:-default}` in compose.
2. **Profiles**: default = full platform; `harness` adds mock-rtmp; `stripe` adds stripe-mock; `tls` adds caddy; `observability` can be default-on (it is part of the platform) — decide and document.
3. **Postgres image** `infra/postgres/Containerfile`: FROM `docker.io/library/postgres:17.11-trixie`, add the **WAL-G v3.0.9** static binary (download in a build stage from the GitHub release with a pinned SHA-256 checksum you verify and record), config for `archive_mode=on`, `archive_command='wal-g wal-push %p'`, `archive_timeout=60`, env for S3 (Garage) via `WALG_S3_PREFIX=s3://commonair-backups/wal`, `AWS_ENDPOINT`, `AWS_S3_FORCE_PATH_STYLE=true`, credentials from env. Archiving must tolerate Garage starting after Postgres (archive_command fails and retries — fine). A `infra/postgres/backup.sh` (base backup push) and `infra/postgres/restore.sh` (fetch latest base backup + WAL replay into a fresh data dir) — the restore drill itself is a later harness scenario, but write and manually exercise the scripts once in your integration test if feasible.
4. **Local dev helper**: update nothing in `scripts/` (not yours) but write `infra/README.md` explaining the stack, profiles, ports, volumes, and how `scripts/infra.ts test` should add `garage` + `garage-init` to its TEST_SERVICES (contract request to the orchestrator with the exact list).
5. **Quadlet units** for production on systemd: `infra/quadlet/*.container|.network|.volume` mirroring compose (generated by hand; document that compose is the dev path and Quadlet the production path; both use the same images and env).
6. Make sure `bun scripts/check-licenses.ts` (it parses `image:` lines in compose.yaml and looks them up in `infra/image-licenses.json`) passes: our own built images should be referenced as `image: ${IMAGE_REGISTRY:-localhost/commonair}/<service>:${IMAGE_TAG:-dev}` (the checker skips templated refs) with `build:` sections.

## Tests

- `infra/tests/*.test.ts` (Bun/Vitest unit): parse compose.yaml (use a YAML parser dependency — `yaml` npm, ISC — in the existing placeholder workspace package `infra/package.json` (`@commonair/infra`) — extend it) and assert the rootless rules: no privileged, no host port < 1024, no socket mounts, every image fully qualified and pinned and present in image-licenses.json, every service has a healthcheck, every service that needs the DB uses the app role.
- Integration (`*.int.test.ts`): bring up **a separate compose project** (`podman compose -p commonair-it-<rand>` with all host ports offset via env, e.g. +20000) containing only postgres(+wal-g image build), valkey, garage, garage-init, mailpit, migrate; assert health, that garage-init created buckets and the key works (S3 PUT/GET via `@commonair/storage`), that `commonair_app` cannot TRUNCATE or create temp tables, and that WAL archiving produced objects in the backups bucket after `select pg_switch_wal()`. Always `down -v` that project in afterAll. NEVER touch the main `commonair` project's containers (they are shared by other agents).
