# @commonair/moderation

Automated moderation primitives for trust & safety ([ADR 0006](../../docs/decisions/0006-automated-moderation.md),
licenses in [ADR 0008](../../docs/decisions/0008-trust-safety-licenses.md), spec in
[docs/testing/e4c-selectors.md](../../docs/testing/e4c-selectors.md)). No database access:
media, the worker and the API own their transactions.

- `constants.ts`: legal floors and matching rules (`MODERATION_CONSTANTS`). Code constants, never settings.
- `thresholds.ts`: the `moderation.thresholds` setting (fail-closed parse) and `tierFor` (scores → T1/T2).
- `seal.ts`: the sealed-evidence format (X25519 + HKDF-SHA256 + AES-256-GCM, WebCrypto). Format in the file header.
- `pdq.ts`, `hashlist.ts`: PDQ (a port of ThreatExchange's BSD-3-Clause code) and hash lists/matcher.
- `classifier.ts`: the scripted classifier (test hooks only). `@commonair/moderation/onnx`: the default
  ONNX classifier, a separate entry point so only the worker loads the native addon.
- `frames.ts`: ffmpeg decoding to raw luma/RGB, PNG/JPEG encoding.
- `model.ts`: the pinned classifier weights (`bun scripts/fetch-model.ts` downloads and verifies them).

Tests and fixtures never use real harmful material: synthetic geometric patterns generated by code
in `fixtures/`, plus the scripted classifier. The real model runs in tests only on benign images.

`onnxruntime-node` must never be in `trustedDependencies`: its postinstall downloads proprietary
CUDA binaries. Container images also set `ONNXRUNTIME_NODE_INSTALL=skip`.

## Operator hash lists

Set `MODERATION_HASHLIST_CSAM` and `MODERATION_HASHLIST_NCII` to local UTF-8 files mounted read-only
into the media service. Each non-comment line starts with one 64-character PDQ hex hash; an
optional comma may introduce ignored metadata. Blank lines and `#` comments are allowed. Use only
lists the operator is authorized to use; do not put list contents in logs or commit them. Empty
paths load as empty lists. A reload keeps the last valid version if parsing fails. The service
records only the category, list version, quality and match distance.

The bundled `.pdq` files are synthetic test fixtures, not operational lists. The code-based
fixture generator is `bun packages/moderation/fixtures/generate.ts`.
