# Email catalog: translator notes

Notes for translators of `locales/<lang>/*.json`, one row per key (or key prefix), ready to paste as
Weblate explanations. Every string may use `{instance}` (the instance name). Keep every
`{placeholder}` and ICU construct exactly as in English (the tests reject a different argument);
`#` in a plural is the count, formatted for your language. Dates, amounts and percentages arrive
already formatted for your language.

| Key                                                                                                       | Note                                                                                                                                                                                                                                                                                 |
| --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `layout.*`                                                                                                | The footer of every email. `{contact}` is a mail link; `{sourceLink}` is a link labelled with `layout.sourceLinkLabel`; `{url}` is the button's link, written out. Text direction comes from the language, not from a string.                                                        |
| `*.subject`                                                                                               | The email subject: keep it short (about 70 characters or fewer where the English is).                                                                                                                                                                                                |
| `*.preview`                                                                                               | The preview line inboxes show after the subject; not shown in the body.                                                                                                                                                                                                              |
| `*.action`                                                                                                | A button label.                                                                                                                                                                                                                                                                      |
| `*Label`                                                                                                  | A label above a value (a date, an amount, a reference) in a list of facts.                                                                                                                                                                                                           |
| `verifyEmail.expiry`, `magicLink.expiry`, `passwordReset.expiry`                                          | `minutes` is the link's lifetime in minutes (a plural).                                                                                                                                                                                                                              |
| `goLiveDigest.subjectOne`, `previewOne`, `headingOne`                                                     | One channel went live: `{channel}` is its name.                                                                                                                                                                                                                                      |
| `goLiveDigest.subjectMany`, `previewMany`, `headingMany`                                                  | Several channels in one digest: `count` is how many (always 2 or more in practice).                                                                                                                                                                                                  |
| `goLiveDigest.item`                                                                                       | One listed channel: its linked name and the broadcast title.                                                                                                                                                                                                                         |
| `goLiveDigest.itemNoTitle`                                                                                | One listed channel without a title (none set, or a mature stream the member has not confirmed 18+ for).                                                                                                                                                                              |
| `goLiveDigest.more`                                                                                       | A link to the home page when more channels went live than the digest lists (20): `count` is how many were left out.                                                                                                                                                                  |
| `dmcaNoticeDecided.bodyActionedPartial`                                                                   | `{removed}` of `{total}` locations (numbers); `total` is at least 2.                                                                                                                                                                                                                 |
| `dmcaCounterNoticeForwarded.statements`, `dmcaCounterNoticeForwarded.restore`                             | Summaries of 17 U.S.C. § 512(g); legal wording, not reviewed by a lawyer. Translate the meaning exactly.                                                                                                                                                                             |
| `enforcementStatement.*`                                                                                  | A statement of reasons (ADR 0019, EU DSA Art. 17). Not reviewed by counsel.                                                                                                                                                                                                          |
| `enforcementStatement.clause.*`, `restriction.*`, `content.*`, `category.*`, `decision.*`, `legalBasis.*` | Also the labels the API shows on the web (`me.enforcement.list` `clauseTitle`); keys follow `@commonair/moderation` `CLAUSES[].titleKey`.                                                                                                                                            |
| `enforcementStatement.content.*`                                                                          | Fills `{content}` in `enforcementStatement.body` ("an action about your {content}").                                                                                                                                                                                                 |
| `enforcementStatement.category.*`                                                                         | Fills `{category}` in `factsClassifierT1`/`T2` ("checks found {category} in content").                                                                                                                                                                                               |
| `enforcementStatement.decision.*`                                                                         | Fills `{decision}` in `factsReview` ("decided: {decision}").                                                                                                                                                                                                                         |
| `enforcementStatement.appealSuspended`                                                                    | A suspended account cannot start a new session: only one still signed in reaches the appeals page.                                                                                                                                                                                   |
| `enforcementStatement.staffAction.facts`                                                                  | A staff action with no moderation case (a report resolved, a suspension): `{clause}` is the rule broken, `{appliedAt}` when, `{action}` comes from `staffAction.action.<source action>` (report.resolve, user.suspend, channel.suspend). Never cite a case. Not reviewed by counsel. |
| `paymentReceipt.*`                                                                                        | The receipt a payer gets once a payment succeeds. Not a tax invoice.                                                                                                                                                                                                                 |
| `newSignIn.deviceUnknown`                                                                                 | Shown as the device when the browser could not be identified from its user agent.                                                                                                                                                                                                    |
| `changeEmailConfirm.*`                                                                                    | Sent to the current address when a member asks to change it; `{newEmail}` is the address asked for. The change needs a second link, mailed to the new address.                                                                                                                       |
