# ADR 0001: Platform name — CommonAir

- Status: accepted
- Date: 2026-10-18

## Context

The platform needs a name before any code is written. The name appears in the
repository (`abolishus/<repo>`), npm package scope, the `SITE` config module, the
trademark policy, and every user-facing surface.

Two candidates were proposed: **bcon.tv** (pronounced "beacon") and
**sitch.tv**. Both domains were reported available. We were free to propose a
better name if research turned one up.

Criteria:

1. No confusing overlap with existing products, especially streaming, video,
   or gaming brands.
2. GitHub org/repo, npm scope, and social handles obtainable.
3. Reads and sounds right in a sentence: "watch me on \_\_\_", "I stream on
   \_\_\_". A listener must be able to type it after hearing it once.
4. Suggests community and shared ownership (we are a cooperative).
5. Domain available (`.tv` preferred). We do not buy domains in this build.

## Research (2026-10-18)

### bcon.tv ("beacon")

- **beacon.tv is Critical Role's membership streaming service** (launched May
  2024; ad-free shows, early access, exclusive series). Critical Role is one of
  the best-known Twitch-native creator brands. A name spoken "beacon" in the
  live-streaming space collides head-on with it: someone told "watch me on
  beacon" will type `beacon.tv` and land on Critical Role.
- **Brightcove Beacon** is a commercial OTT video-streaming platform. Rovio's
  "Beacon" is a games platform. Xbox Live had "Beacons". The "Beacon" mark is
  crowded exactly in our classes (video streaming, games, entertainment
  software).
- The spelling `bcon` does not follow from the pronunciation, which defeats
  criterion 3.
- GitHub user `bcon` is taken; `bcon.bsky.social` is taken; a popular GitHub
  project `sanohiro/bcon` (terminal emulator) uses the name.
- Verdict: **rejected**. The homophone conflict with beacon.tv alone is
  disqualifying.

### sitch.tv

- **Sitch** is a venture-backed AI dating app in New York (a16z Speedrun, M13;
  2025 seed). There was also a defunct 2012 events app "Sitch" and
  `sitch.social`. Different trademark class from ours, so lower legal risk, but
  the name is not distinctive.
- "Sitch" rhymes with "Twitch". That helps recognition ("the Twitch
  alternative") but reads as derivative and invites a confusion argument from
  the dominant incumbent. We want to stand on our own.
- "Sitch" (slang for "situation") says nothing about community or ownership.
- GitHub user `sitch` is taken; `sitch.bsky.social` is taken; npm `sitch` is
  taken.
- Verdict: viable but weak on criteria 1, 2 and 4.

### Alternatives explored

Checked `.tv` registrations on `whois.nic.tv`: `stoop.tv` (registered 2026),
`hearth.tv`, `mutual.tv`, `campfire.tv`, and `bonfire.tv` are all registered.

**commonair.tv**: the `.tv` registry returns "No Data Found" (unregistered at
time of research).

- "Common" + "on air": the commons (shared, member-owned) + broadcasting. It
  says what we are: airtime held in common.
- No company, app, or product named CommonAir/Common Air turned up in search.
- GitHub user/org `commonair`: free. npm `commonair`: free.
  `commonair.bsky.social`: free.
- Sentences: "Watch me on CommonAir." "I stream on CommonAir." "CommonAir is
  owned by its streamers and viewers." Spelled the way it sounds; two common
  English words, so it survives being said aloud once.
- Drawbacks: longer than the four- or five-letter candidates; `commonair.org`
  is registered by someone else (we use `.tv`); could be misheard as "common
  area" in noisy settings, which is harmless and on-theme.

We did not run a formal USPTO/EUIPO clearance search (the USPTO search tool is
not scriptable from here); the co-op should run one before incorporation, along
with checking X/Twitch/YouTube/Instagram handles.

## Decision

The platform is named **CommonAir**, domain **commonair.tv**.

- Repository: `abolishus/commonair` (public)
- npm scope: `@commonair/*`
- Display name: `CommonAir`; lowercase slug `commonair`
- Contact addresses live in `packages/config` (`SITE`), never elsewhere

The local folder is still called `bcon` from before the decision. That is
cosmetic; nothing in the code refers to it.

## Consequences

- `TRADEMARKS.md` claims "CommonAir" and the logo for the co-op.
- If a clearance search turns up a conflict, renaming is one change to
  `packages/config` plus the package scope. The stray-domain test enforces that
  the name lives in one place.
